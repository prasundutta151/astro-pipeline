Getting Started

Follow these steps to set up your environment and start using astro-pipeline.

1. Recommended Installation (Virtual Environment)

To avoid conflicts with other Python packages, it is highly recommended to use a virtual environment:

# Create the environment
python3 -m venv astro_env

# Activate it (macOS/Linux)
source astro_env/bin/activate

# Install the package in editable mode for development
pip install -e .

2. Alternative Installation (User level)

If you do not want to use a virtual environment, install it to your user directory:

pip install --user astro-pipeline

3. Custom Installation Directory

To install the package into a specific directory:

pip install astro-pipeline --target /path/to/your/folder

Note: You must add this directory to your PYTHONPATH to use it.
